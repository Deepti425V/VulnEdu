Understanding CVSS Scores

CVSS scores help you measure, compare, and prioritize vulnerabilities. Use the range and severity to decide: Patch now, or monitor?

Score Breakdown

Score Range Severity What this means Examples
9.0 – 10.0 Critical Immediate action needed. Show Critical CVEs
7.0 – 8.9 High Patch as soon as possible. Show High CVEs
4.0 – 6.9 Medium Review and patch soon. Show Medium CVEs
0.1 – 3.9 Low Monitor for now. Show Low CVEs

How CVSS v3.1 Works

CVSS (Common Vulnerability Scoring System) v3.1 calculates vulnerability severity using 8 metrics across 3 groups:

Exploitability Metrics

How easy is it to exploit?

  • Attack Vector
  • Attack Complexity
  • Privileges Required
  • User Interaction

Impact Metrics

What damage can be done?

  • Confidentiality Impact
  • Integrity Impact
  • Availability Impact

Scope

Boundary consideration

  • Unchanged: Same component
  • Changed: Affects other components
BaseScore = min(10, Impact + Exploitability)
Where Impact and Exploitability are calculated from the 8 metrics above.
